# 장면 · VlogTool

**Windows용 브이로그 편집기 · v0.5.0**

영상 앞뒤 자르기, 자막, 색 보정, 마이크 녹음과 MP4 내보내기를 지원합니다. 영상과 음성은 PC에서 처리합니다.

## 다운로드 및 실행

1. [최신 릴리스](https://github.com/zamgune/VlogEditor/releases/latest)에서 `VlogTool-0.5.0-win-x64.zip`을 받습니다.
2. 압축을 **모두 풀고**, 쓰기 가능한 폴더에서 `Start-VlogTool.cmd`를 두 번 클릭합니다.
3. 처음 실행할 때 영상 처리 도구(FFmpeg)를 다운로드합니다. 이때만 인터넷이 필요하며, Node.js를 따로 설치할 필요는 없습니다.

Windows 11 x64에서 검증했습니다. 코드 서명은 아직 적용되지 않았습니다.

## 간단한 사용법

1. **영상 가져오기**: `＋ 영상 가져오기`로 MP4/MOV 파일을 선택합니다. 편집용 사본 준비가 끝나면 타임라인에 표시됩니다.
2. **앞뒤 자르기**: 클립의 왼쪽·오른쪽 끝을 드래그하거나 속성창에서 시작·종료 시간을 입력합니다. 재생 위치에서 `여기부터 시작` / `여기까지 사용`도 가능합니다. 클립을 드래그하면 순서가 바뀝니다.
3. **자막 꾸미기**: 자막·제목을 여러 개 추가하고 글꼴, 크기, 색, 위치와 표시 시간을 설정합니다. **문구** 탭에서 일부 글자를 선택하면 글자마다 다른 서식을 적용합니다. 마루 부리 5가지 굵기, **나눔손글씨 펜**, Noto Sans KR, Noto Serif KR을 제공합니다.
4. **목소리 녹음**: Windows에 마이크를 연결한 뒤 `음성 녹음`에서 장치를 선택하고 `마이크 확인`으로 입력을 확인합니다. 원하는 재생 위치에서 `녹음 시작`을 누르면 영상과 함께 녹음됩니다. `녹음 정지` 후 음성 위치·앞뒤 구간·음량을 조절할 수 있습니다. 소리 재유입을 줄이려면 이어폰을 사용하세요.
5. **저장·내보내기**: `저장`은 편집 내용을 `.vlog.json`으로 보관하고, `내보내기`는 자막과 녹음이 포함된 MP4를 만듭니다. 같은 파일명을 선택하면 Windows의 덮어쓰기 확인 창이 나타납니다. 승인한 파일은 새 영상이 완성·검증된 뒤 교체하며, 도중 취소하거나 실패하면 기존 파일을 보존합니다. 진행 화면은 **자막·꾸미기 → 영상 만들기 → 확인·저장** 단계와 현재 단계 진행률, 처리한 영상 길이, 경과 시간을 보여 줍니다.

**프로젝트 보관:** 원본 영상은 기존 위치에 두세요. 녹음이 있는 프로젝트는 같은 위치의 `.vlog.json.assets` 폴더도 함께 보관해야 다시 열 수 있습니다. 녹음 후 영상 순서나 길이를 바꾸면 음성 위치를 확인하세요.

| 단축키 | 기능 |
|---|---|
| Space | 재생·일시 정지 / 녹음 중에는 정지·저장 |
| ← / → | 한 프레임 이동 |
| S / Delete | 선택 클립 분할 / 삭제 |
| Q / W | 재생 위치에서 앞부분 / 뒷부분 자르기 |
| Ctrl+C / Ctrl+V | 선택 자막 복사 / 붙여넣기 |
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| Ctrl+S | 프로젝트 저장 |
| Esc | 진행 중인 녹음 취소 |

SDR 8비트 MP4/MOV 입력, 30fps 편집을 지원합니다. HDR 입력과 자동 자막 생성은 아직 지원하지 않습니다. 녹음은 한 번에 최대 30분이며, Windows에서 마이크 접근이 허용되어 있어야 합니다.

## 자막과 화면 편집

### 미리보기 중심 편집 · 기기별 안전 영역

상단에서 **영상·자막·제목·꾸미기·녹음**을 추가하고, 화면의 글이나 도형을 선택해 **빠른 편집** 도구로 수정합니다. **상세 편집**을 누르면 옆 패널에서 표시 시간·부분 서식·그라데이션·움직임 등을 조절합니다. **크게 보기**에서도 편집할 수 있고 타임라인 높이를 끌어서 바꿀 수 있습니다. **미디어 / 자막 목록 / 내 스타일**로 보관함을 열고 ‘닫기’로 미리보기를 넓힙니다.

상단 **레이아웃**에서 작업 방식에 맞게 화면을 선택할 수 있습니다.

- **상하분할형:** 미리보기 아래에 빠른 편집 도구, 화면 하단 전체에 타임라인을 표시합니다.
- **좌우 분할형:** 한쪽에는 높이를 넉넉하게 쓰는 미리보기, 반대쪽에는 편집 도구와 타임라인을 모읍니다. **좌우 바꾸기 ⇄**로 미리보기 위치를 바꾸고 가운데 경계를 끌어 너비를 조절하세요. 상세 편집과 보관함은 도구 자리에서 열리며 ‘닫기’를 누르면 빠른 편집으로 돌아옵니다.

배치와 좌우 위치, 분할 비율 및 타임라인 높이는 이 PC에서 자동으로 기억합니다. 배치를 전환해도 선택한 글과 재생 위치는 유지되며 프로젝트와 출력 영상에는 영향을 주지 않습니다. **↺ 화면 배치 초기화**를 누르면 상하분할형 기본 배치로 돌아갑니다.

1. 미리보기의 **원본 보기 → 기기에서 보기**를 선택합니다.
2. iPhone 16 Pro, Galaxy S25, Flip6 펼침, Fold6 바깥·펼침 중 기기를 선택하고 세로·가로 방향을 바꿉니다. **사용자 지정**에서 해상도와 이름을 저장할 수도 있습니다.
3. **YouTube 쇼츠 / 일반 영상**을 고릅니다. 주황색 빗금은 버튼·설명·재생 조작부에 가려질 수 있는 곳입니다. 겹치는 글은 주황 테두리와 경고로 표시됩니다. 경고를 누르면 해당 글을 선택합니다.
4. **가이드 설정**에서 여백을 보정합니다. 일반 영상은 재생 조작부 보임·숨김을 선택하고 하단 배너 높이를 추가로 고려할 수 있습니다.

**영상 전체 보기**는 전체 영상을 보여 주고, **화면 채우기**는 기기 화면에 맞춰 가장자리가 잘리는 상황을 확인합니다. 기기·가이드 설정은 이 PC에 저장되며 영상의 출력 해상도나 자막 좌표를 바꾸지 않습니다. 실제 출력 해상도는 상단 **출력 설정**에서 바꿉니다. 안내선과 기기 테두리는 MP4에 들어가지 않습니다.

가이드는 **공식 안전 보장 규격이 아닌 예상 영역**입니다. 유튜브 앱의 상태에 따라 달라지며 펼친 댓글창·임의의 광고 팝업·카메라 구멍의 정확한 모양은 재현하지 않습니다. 첫 기본값은 쇼츠 상단 10%·하단 25%·왼쪽 6%·오른쪽 18%, 일반 영상 조작부 상단 10%·하단 18%입니다. 현재 프레임에 보이는 자막과 제목을 검사하며, 꾸미기 도형은 기본 경고 대상에서 제외합니다. [유튜브 시각적 가이드 안내](https://support.google.com/youtube/answer/16215842?hl=ko)

위 화면 개편과 기기별 안전 영역은 v0.5.0부터 포함됩니다.

### 자막 배치와 저장

**앞부분 자르기 개선:** 남길 시작 장면에 재생선을 놓고 타임라인의 **앞부분 자르기** 또는 **Q**를 누르세요. **W / 뒷부분 자르기**는 현재 프레임까지 남깁니다. 입력칸에서 글을 쓰는 동안에는 단축키가 작동하지 않습니다. 왼쪽 손잡이를 끌면 손잡이가 마우스를 따라가고 잘라낼 부분이 빗금으로 표시되며, 놓으면 빈틈이 닫힙니다. **Esc**로 취소, **Ctrl+Z**로 되돌릴 수 있습니다. 편집기 재생 중 영상 준비가 늦어져도 위치를 반복해서 건너뛰지 않도록 재생 동기화를 수정했습니다.

**자석 켜짐** 상태에서 자막을 다른 자막 아래나 옆으로 끌면 가장자리·가운데와 사이 간격이 맞춰집니다. 세 줄 이상은 기존 간격에 맞춰 배치할 수 있으며, 안내선과 간격 숫자가 표시됩니다. **Alt를 누른 채 끌면** 자유롭게 이동합니다.

꾸며 둔 여러 제목과 도형을 **기본 자막 스타일**로 저장할 수 있습니다. 상단 **자막 목록 → 현재 화면 선택 → 이름 입력 → 기본 자막 스타일로 저장**을 누르세요. 이후 **＋ 자막**을 누르면 부분 글꼴·크기·그라데이션·도형 배치가 함께 추가됩니다. 다른 프로젝트와 앱 재실행 후에도 유지되며, 저장한 묶음을 불러와 편집·덮어쓰기·이름 변경할 수 있습니다. [자세한 사용법](docs/CAPTION-GROUPS.md)

자막을 선택하고 **Ctrl+C → Ctrl+V**로 복사·붙여넣기할 수 있습니다. 상단 **자막 목록 → 자막 복사·붙여넣기**에서 **뒤쪽 빈 시간에 자동 배치**를 켜면 같은 장면 뒤쪽의 충분한 빈 구간에 길이를 유지해 배치합니다. 옵션은 복제 버튼에도 적용되며, 문구 입력 중에는 글자 복사·붙여넣기로 동작합니다.

자막을 선택하고 **상세 편집 → 표시 시간**에서 시작·끝·길이를 조절합니다. 예를 들어 3초 장면에 1·2번 자막은 **0~1.5초**, 3·4번 자막은 **1.5~3초**로 설정하면 두 개씩 교체됩니다. 타임라인 자막 막대의 가운데를 끌면 시간 이동, 양끝을 끌면 길이 조절입니다. 새 일반·강조 자막은 현재 재생 위치에서 시작합니다.

**문구** 탭에서 글자 일부를 선택해 서로 다른 글꼴·크기·색을 적용할 수 있습니다. **꾸미기 → 배경**에서는 자막 배경 그라데이션의 두 색과 각도를 조절합니다. **소프트**는 부드럽게 섞이고, **하드**는 두 색이 선명하게 나뉩니다. 상단 **꾸미기**에서는 독립된 사각형·타원을 추가합니다. **나눔손글씨 펜** 글꼴도 포함되어 있습니다. [부분 글꼴과 꾸미기 사용법](docs/RICH-TEXT-DECORATIONS.md)

## 소스에서 실행

Windows x64와 Node.js 22.12 이상이 필요합니다. 위의 ZIP으로 실행할 때는 Node.js가 필요 없습니다.

```powershell
git clone https://github.com/zamgune/VlogEditor.git
cd VlogEditor
npm ci
npm run setup:electron
npm run setup:ffmpeg
npm start
```

검사: `npm test` · Windows ZIP 생성: `npm run package:windows`
