# 0.3 영상 길이 조절 — 2026-09-27

클립 양끝 드래그와 속성창 상단의 초 단위 길이 입력을 추가했다. 시작/종료 프레임 입력도 유지한다.
뒤 클립은 리플 방식으로 이어진다. 길이는 30fps 정수 프레임으로 반올림하고 원본 범위 안에서 최소 1프레임을 보장한다.
원본 길이 복원은 해당 클립의 전체 구간을 복원하며 색 보정/음량은 유지한다. 속도 변경이나 프레임 반복 연장은 포함하지 않는다.

드래그 시작의 클립/마우스/스크롤/확대 상태를 기준으로 계산한다. 조절 중 해당 시작/마지막 사용 프레임을 미리보기하며, 완료 후 정확한 FFmpeg 정지 프레임을 표시한다.
Pointer capture로 트랙 밖에서 놓아도 완료한다. Esc·포인터 취소·창 포커스 상실은 원래 구간/선택/재생 위치/히스토리로 복원한다.
드래그 중에는 중간 상태를 자동 저장하지 않으며 완료 시 한 번의 편집으로 기록한다. 변화가 없거나 원위치로 돌아오면 redo 기록도 보존한다.
1프레임처럼 작은 선택 클립에도 바깥쪽 손잡이가 남아 다시 늘릴 수 있다. 프로젝트 포맷은 기존 버전 2를 유지한다.
