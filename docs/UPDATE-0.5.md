프로젝트 기본 맞춤은 전체 보이기(contain) 또는 화면 채우기(cover). 여백은 검정/흰색 버튼 및 단색 선택기로 지정한다.
각 클립은 프로젝트 설정 따름/전체 보이기/화면 채우기를 개별 저장한다. 채우기의 x/y 0–100%는 잘리는 원본 영역의 좌우/상하 위치이며 50%는 가운데다.
비율과 배경은 프로젝트 전체에 적용되고, 기본 맞춤 변경은 inherit 클립에 적용된다. 모든 변경은 저장/자동 저장/실행 취소 대상이다.
채우기 위치의 연속 슬라이더 조절은 한 번의 실행 취소로 기록한다. 분할된 클립은 원래 화면 맞춤 값을 복제한다.

## 미디어 경로

이전 16:9 여백이 이미 붙은 편집용 사본 대신, 회전 및 SAR를 보정한 원본 비율의 긴 변 1920px 사본을 만든다. 캐시 키는 v3로 분리한다.
기존 프로젝트를 열면 새 사본을 준비하고 displayWidth/displayHeight를 갱신한다. 원본 경로/지문/프레임 수와 편집 구간을 검증하며 원본을 수정하지 않는다.
프로젝트 포맷 버전 3. 버전 1/2는 기존 width/height를 유지하고 기본 contain/검정 배경/클립 inherit로 마이그레이션한다.

원본 크롭 사각형, 출력 크기, 여백 좌표는 공통 함수에서 계산한다. crop/offset은 YUV420에 맞게 짝수 픽셀로 맞춘다.
브라우저는 같은 사각형을 CSS 비율로 표현하고 FFmpeg는 crop/scale/pad로 렌더링한다. 보정은 영상에 적용하고 새 여백 색은 보정과 분리한다.
정지 PNG는 출력 가로/세로의 절반이다. 출력 파일은 선택한 해상도와 프레임 수를 검사한 뒤 완성 파일로 만든다.
