# 0.8 · 마이크 내레이션 녹음

## 사용법

왼쪽 **음성 녹음**에서 Windows 기본 마이크 또는 연결된 마이크를 선택합니다. **마이크 확인**은 입력 막대를 켜며 파일을 만들지 않습니다. **마이크 끄기** 또는 다른 탭으로 이동하면 마이크를 해제합니다.

타임라인 눈금으로 시작 위치를 고른 뒤 **녹음 시작**을 누르면 영상을 재생하면서 목소리를 녹음합니다. **녹음 정지 / Space**로 저장하고 **녹음 취소 / Esc**로 버립니다. 영상 끝 또는 한 번에 30분 한도에서 자동 정지합니다. 녹음 중에는 영상 편집·프로젝트 변경·내보내기를 잠급니다. 녹음 중 창을 닫으면 녹음을 먼저 저장하고 창은 유지합니다.

녹음 목록의 **위치 (초)**는 타임라인 시간이며 **음성 앞뒤 자르기**는 녹음 원본의 구간입니다. 음량은 0–100%, 음소거·삭제·실행 취소를 지원합니다. 음성 트랙은 영상 바로 아래에 표시하고 겹치는 녹음은 여러 줄로 나눕니다. 녹음 중에는 기존 녹음의 미리보기 소리를 끄며 원본 영상 소리는 현재 음량으로 재생합니다. 마이크 입력 자체를 스피커로 재생하지 않습니다. 이어폰 사용을 권장합니다.

음성 위치는 타임라인의 절대 시간에 고정됩니다. 영상을 이동·자르거나 삭제해도 녹음 원본은 유지됩니다. 영상 밖으로 나간 구간은 안내하고 미리보기·MP4에서 제외합니다. 녹음 위치를 다시 맞추면 사용할 수 있습니다.

## 저장 및 복구

- 녹음은 앱 사용자 데이터의 `recordings/`에 48kHz 모노 PCM WAV로 영구 저장합니다. 캐시와 구분합니다.
- 녹음 완료 후 자동 저장을 마친 뒤 편집 잠금을 해제합니다. 저장 실패 시 녹음 데이터를 메모리에 유지하며 **저장 다시 시도 / 녹음 버리기**를 표시합니다.
- 프로젝트를 명시적으로 저장하면 `<프로젝트 파일명>.assets/`에 녹음 사본을 보관하고 JSON에는 상대 경로를 기록합니다. JSON과 해당 폴더를 함께 옮겨 다시 열 수 있습니다. 원본 영상 파일은 기존 경로에 별도로 보관해야 합니다.
- 삭제·실행 취소를 지원하기 위해 녹음 파일 자체를 자동 삭제하지 않습니다. 기존 프로젝트/백업의 녹음 사본을 덮어쓰지 않습니다.
- 프로젝트 v6이며 v1–v5는 빈 음성 트랙으로 읽습니다. 이전 앱 버전에서는 v6을 열 수 없습니다.
- 열기/출력에서 녹음 파일의 SHA256을 확인합니다. 누락·변경되면 안내하고 출력을 중단합니다.

## 재생과 출력

하나의 단조 증가 시계로 영상 재생 위치와 녹음 시작을 맞추며, 클립 전환 후 영상이 지연되면 현재 위치로 맞춥니다. 녹음 파일은 프레임당 1600샘플로 정규화합니다. MP4는 원본 오디오와 음성들을 각 구간·위치·음량·음소거에 맞춰 섞으며, 겹친 소리의 과도한 피크를 제한합니다. 영상 길이가 출력 길이를 결정합니다.

브라우저 미리보기의 디코딩 지연, 마이크·오디오 드라이버의 입력 지연은 장치에 따라 다릅니다. 프레임 단위의 실기기 지연 보정을 보장하지 않습니다. 입력 지연이 느껴지면 녹음의 **위치 (초)**로 조절할 수 있습니다.

## 권한과 오류

마이크 확인/녹음 시작을 누른 뒤에만 편집창의 오디오 권한을 허용합니다. 카메라·화면 캡처·외부 창은 허용하지 않습니다. 녹음은 이 PC에서 처리합니다.

권한 거부 시 Windows **설정 → 개인정보 및 보안 → 마이크 → 데스크톱 앱 접근** 안내를 표시합니다. 장치가 없거나 사용 중인 경우 마이크 선택/연결 확인을 안내합니다. 연결이 끊기면 그때까지 수집한 음성을 저장하고 마이크를 해제합니다.

## 검증

`npm test`, `npm run test:narration`, 기존 `npm run test:trim` / `npm run test:font-trim`으로 확인합니다. 녹음 검사 결과와 화면은 `artifacts/latest-narration.json` 및 해당 `output/playwright/narration-…/` 폴더에 기록합니다.

녹음 검사는 Chromium의 파일 기반 가상 마이크를 사용합니다. 실제 사용자의 마이크를 열지 않습니다. 테스트 신호 측정에서는 잡음 억제를 꺼서 997Hz 신호를 보존하며, 앱 기본 녹음에서는 에코 제거·잡음 억제를 사용합니다. 시작 위치, 컷을 가로지르는 녹음, 자동 정지, 마이크 해제, 원본 소리와 녹음의 주파수 검출, 음량·음소거·위치·자르기, 삭제/실행 취소, 취소, 장치/권한 오류, 앱 재시작과 프로젝트 폴더 이동을 확인합니다.

물리 Windows 마이크별 연결·입력 지연·음질은 실기기 검증이 필요합니다.
