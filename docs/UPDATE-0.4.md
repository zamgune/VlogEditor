# 0.4 클립을 눌러 위치 이동 — 2026-09-27

타임라인의 영상 본문을 누른 채 끌어 클립 앞뒤로 옮길 수 있다. 단순 클릭은 해당 장면 선택/미리보기이며, 이동은 5px 이상 움직였을 때 시작한다.
본문과 기존 ⠿ 손잡이는 같은 포인터 동작을 사용한다. 눈금/재생선 탐색, 양끝 트리밍, 휠/가운데 버튼 화면 이동은 유지한다.

이동할 클립의 반투명 표시와 삽입 경계를 보여주며 실제 순서는 놓을 때만 변경한다. 클립 중간점을 기준으로 앞/뒤 경계를 고르고, 원래 위치에서 빼는 인덱스를 보정한다.
가장자리 자동 스크롤과 휠 이동 시 스크롤 오프셋을 반영한다. 이동 중 확대/다른 편집은 잠그고 pointer capture로 놓기를 추적한다.
Esc, 포인터 취소, 창 포커스 상실, 영상 트랙 밖에 놓기는 순서를 변경하지 않는다. 원위치에 놓거나 클릭만 하면 undo/redo 기록도 바뀌지 않는다.
프로젝트는 놓을 때 한 번만 변경/자동 저장되므로 Ctrl+Z 한 번으로 되돌릴 수 있다. 이동한 클립의 구간/색/음량/ID와 전체 길이는 유지한다.
재생 위치는 이동 전 보던 클립의 같은 원본 프레임을 따라간다. 한 줄 리플 타임라인으로 빈 구간이나 영상 겹침을 생성하지 않는다.
