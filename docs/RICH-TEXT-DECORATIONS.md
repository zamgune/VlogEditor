# 부분 글꼴·그라데이션·도형 꾸미기

## 한 문장에 여러 글꼴과 크기

1. 자막 또는 제목을 선택하고 오른쪽 **문구** 탭을 엽니다.
2. 문구 입력창에서 바꿀 글자만 드래그해서 선택합니다.
3. **선택 글꼴**, **선택 크기**, **선택 굵기**, **선택 색**을 조절합니다. 크기는 숫자를 입력하거나 슬라이더를 움직이면 즉시 반영됩니다. 숫자 입력 중 Esc를 누르면 입력 전 크기로 돌아갑니다.
4. 다른 부분을 선택해 다른 서식을 적용합니다. 예를 들어 앞부분은 고딕 60, 뒷부분은 나눔손글씨 펜 30으로 설정할 수 있습니다.

**선택 부분 기본값**은 선택한 글자만 기본 서식으로 되돌리고, **부분 서식 모두 지우기**는 문구 전체의 부분 서식을 없앱니다. 오른쪽 **꾸미기** 탭은 기본 서식, **문구** 탭은 선택한 글자의 서식을 바꿉니다. 부분 서식은 기본 서식보다 우선합니다.

문구를 수정해도 다른 부분의 서식은 유지됩니다. 미리보기의 모서리로 자막 크기를 바꾸면 부분별 크기도 비례해서 조절됩니다. 글 그룹에 저장하면 문구별 부분 글꼴·크기·색도 함께 저장됩니다.

## 자막·제목의 배경 그라데이션

오른쪽 **꾸미기 → 배경 → 배경 그라데이션**을 켭니다. 시작 색과 끝 색, 각도(0~360°), 배경 불투명도·둥글기·안쪽 여백을 조절하세요. 90°는 왼쪽에서 오른쪽, 180°는 위에서 아래로 변합니다. **색 순서 바꾸기**로 양쪽 색을 바꿀 수 있습니다.

**스타일**에서 **소프트 / 하드**를 선택할 수 있습니다. 소프트는 두 색이 부드럽게 이어지고, 하드는 가운데를 기준으로 두 색이 섞이지 않고 선명하게 나뉩니다. 하드에서도 각도를 바꾸면 분리 방향이 회전합니다. 기존 프로젝트의 그라데이션은 소프트로 열립니다.

그라데이션은 글자 뒤의 배경에 적용됩니다. 일반 스타일 보관함과 글 그룹에도 함께 저장되며, 그라데이션을 끄면 기존 단색 배경으로 돌아갑니다.

소프트·하드 선택은 프로젝트, 내 스타일, 기본 자막 묶음에 함께 저장되며 MP4 출력에도 적용됩니다. `npm run test:gradient-styles`로 여섯 각도의 색 분리, 부분 글꼴, 저장·재실행 및 출력 색상을 확인합니다.

## 별도의 도형 추가

왼쪽 **꾸미기 → ＋ 사각형 / ＋ 타원**으로 추가합니다. 도형은 자막과 독립된 항목입니다.

- 미리보기에서 도형을 끌어 이동하고, 선택한 도형의 오른쪽 아래 모서리를 끌어 크기를 바꿉니다.
- 오른쪽에서 색상·불투명도·테두리·사각형 둥글기, 가로·세로 위치와 너비·높이를 숫자로 조절합니다.
- **자막 뒤 / 자막 앞**으로 글과 겹치는 순서를, **맨 앞으로 / 맨 뒤로**로 도형끼리의 순서를 정합니다.
- **표시 시간**으로 선택한 장면 안의 시작·끝을 설정합니다. 새 도형은 현재 재생 위치부터 장면 끝까지 표시됩니다.
- 복제·삭제·실행 취소가 가능하며, 드래그 중 Esc로 취소할 수 있습니다. 도형을 선택한 상태에서 방향키로 미세 이동하고 Shift를 누르면 더 크게 움직입니다.

도형은 최대 500개이며 프로젝트에 저장됩니다. 왼쪽 **자막 목록 → 현재 화면 선택 → 기본 자막 스타일로 저장**으로 제목과 도형을 함께 보관할 수 있습니다. 다음 **＋ 자막**부터 저장한 구성을 사용합니다. [묶음 저장과 기본 지정](CAPTION-GROUPS.md)

## 나눔손글씨 펜

제공된 `NanumPen.ttf` 원본을 앱에 포함했습니다. 글꼴 목록에서 **나눔손글씨 펜**을 선택하세요. 이 글꼴은 원본의 Regular(400) 굵기를 사용합니다. 별도 Windows 설치 없이 미리보기와 MP4에 적용됩니다. 저작권과 라이선스는 [외부 구성요소 안내](THIRD_PARTY.md)에 정리했습니다.

프로젝트 저장 형식은 8, 글 보관함 형식은 4입니다. 이전 프로젝트와 보관함은 열 때 변환합니다. 새 기능이 포함된 파일은 v0.4.0 이상에서 열어 주세요.

검사: `npm run test:rich-decoration` — 실제 입력·선택, 그룹 저장, 도형 편집, 표시 시간, 재실행, 작은 창과 MP4 픽셀을 비교합니다. 테스트에는 합성 영상과 별도 테스트 보관함을 사용합니다.
