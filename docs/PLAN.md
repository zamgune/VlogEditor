# 구현 계획과 완료 기준

요구사항 원본: ../windows_vlog_editor_build_prompt.md. 2026-09-27 최초 작업.
기존 폴더에는 요구사항 문서만 있었고 앱/저장소/AGENTS.md는 없었다.

## 이번 작업의 범위
실행 가능한 Electron + React + TypeScript 기반, 두 영상의 구간 연결 MP4 출력 검증.
0단계 전체나 최종 핵심 버전 완료를 의미하지 않는다. 합성 테스트와 실제 촬영본 검증은 구분한다.

## 단계별 진행
0. 기술 검증: 두 입력 컷 연결 → 동일 자막 이미지의 한글 미리보기/출력 비교 → 움직이는 수동 모자이크 → 마이크 녹음/시각 동기 검증. 각각 증거 파일과 결과 기록. 이번 작업은 첫 항목과 그 실행 기반.
1. 기본 편집기: 다중 가져오기, 코덱 검사, 프록시, 분할/숫자 트림/리플 삭제/순서/프레임 이동, 저장/복원/복구/되돌리기, 출력. 다음에 트림 핸들·정적 확대/이동/크롭·누락 미디어 재연결을 보강하고 실제 촬영본으로 확인.
2. 자막/음악: 클립에 연결된 자막의 원본 프레임 구간, 분할 시 교집합 복제, 트림 시 교집합 표시. 하나의 자막 PNG를 미리보기/출력에 사용. 스타일 저장, BGM 트림/절대 위치/페이드.
3. 나레이션: 마이크 확인/3초 카운트다운/입력 레벨, monotonic clock 기준 시작 오프셋, 녹음 파일 영구 보존, 재녹음 확인 전 기존 파일 유지, 구간 기반 음악 ducking. 시작/중간/끝 지연 실측.
4. 모자이크: 수동 영역/원본 정규화 좌표/키프레임 먼저. 로컬 모델 후보 검증 후 모델 고정/포함. 추적/장면 전환/짧은 보간, 진행/취소, 수동 보정 레이어 보존. 익명화 보장 금지.
5. 실사용/패키징: 실제 촬영본 1–3분 편집, 다양한 얼굴/모션/회전/VFR 입력 검증. 런타임/바이너리/모델/글꼴과 라이선스 포함 Windows x64 패키지. 현재 개발 실행기는 설치 패키지가 아님.

## 완료 정책

후속 사용자 요청으로 0.3 트림 핸들, 0.4 본문 드래그 이동, 0.5 숏츠 포함 6개 비율·fit/fill·크롭 위치·여백 색을 구현했습니다. 임의 배율/자유 크롭과 누락 미디어 재연결은 후속 범위입니다.

각 단계에서 typecheck, 모델 자동 테스트, 실제 FFmpeg 출력, Electron 구동 확인.
검증하지 않은 항목은 보류로 기록. 사용자 미디어를 임의 검색하거나 업로드하지 않음.
첫 마일스톤 이후 단계별로 실행 가능한 상태를 유지하며 진행.
