# 장면 · VlogTool v0.5.0

영상을 크게 보면서 편집할 수 있도록 화면을 개편하고, 작업 방식에 맞는 두 가지 배치와 기기별 예상 가림 영역을 추가했습니다.

- **두 가지 레이아웃:** 상단에서 **상하분할형 / 좌우 분할형**을 선택합니다. 좌우 분할형은 한쪽에 미리보기, 반대쪽에 편집 도구와 타임라인을 모읍니다.
- **좌우 위치와 크기 조절:** **좌우 바꾸기 ⇄**와 가운데 경계로 미리보기 위치·너비를 조절합니다. 배치와 크기는 다음 실행 때도 기억하며, 전환 중 선택한 글과 재생 상태를 유지합니다.
- **빠른 편집:** 화면에서 글·도형을 선택해 문구·글꼴·크기·색상·배경을 수정합니다. 상세 편집에서 부분 서식, 그라데이션, 애니메이션과 스타일 저장을 이어서 사용할 수 있습니다. 크게 보기에서도 편집할 수 있습니다.
- **기기에서 보기:** iPhone 16 Pro, Galaxy S25, Galaxy Z Flip6 펼침, Galaxy Z Fold6 바깥·펼침 프리셋을 제공합니다. 세로·가로, 영상 전체 보기·화면 채우기와 사용자 지정 해상도를 지원합니다.
- **유튜브 예상 가림 영역:** 쇼츠의 버튼·설명 영역과 일반 영상의 재생 조작부·하단 배너를 확인합니다. 현재 보이는 제목·자막이 겹치면 이유를 표시합니다. 여백과 배너 높이를 보정해 저장할 수 있습니다.
- **작은 화면 대응:** 창 크기와 Windows 화면 배율에 맞춰 도구를 배치합니다. 타임라인 높이는 두 레이아웃에서 각각 조절할 수 있습니다.

기기 보기와 안내선은 편집 화면에만 적용됩니다. 프로젝트의 출력 해상도·자막 위치를 바꾸지 않으며 결과 MP4에는 들어가지 않습니다. 가림 영역은 보수적인 편집용 예상값이며 실제 유튜브 화면은 앱 상태에 따라 달라질 수 있습니다.

## 다운로드 및 실행

`VlogTool-0.5.0-win-x64.zip`을 받아 **모두 압축 해제**한 뒤 **Start-VlogTool.cmd**를 실행하세요. Windows x64용이며 Node.js는 필요 없습니다. 첫 실행 시 영상 처리 도구를 다운로드하므로 인터넷 연결이 필요합니다.

기존 프로젝트와 자막 스타일을 계속 사용할 수 있습니다. 원본 영상과 프로젝트 옆의 `.vlog.json.assets` 녹음 폴더는 함께 보관하세요. 저장한 화면 배치와 기기 보기 설정은 이 PC에서만 사용합니다.

## 검증

자동 테스트 71개, 기기·화면 비율·방향·맞춤 조합 120개, 두 레이아웃의 125%·150% 배율, 자막 이동 오차 1픽셀 이내, 부분 서식·도형·묶음 저장·재생 유지 검사를 통과했습니다. 안전 영역 표시 전후의 출력 영상도 동일함을 확인했습니다.
