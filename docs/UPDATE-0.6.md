# 0.6 · 제목, 자막, 강조 캡션과 큰 미리보기

## 사용하기

- 영상 선택 → 왼쪽 **＋ 자막**: 첫 일반 자막을 해당 클립 전체에 추가합니다. **＋ 강조**는 현재 위치부터 최대 2초, **＋ 제목**은 영상 전체에 유지되는 제목입니다.
- **자막 목록**에서 문장을 입력합니다. 오른쪽의 8가지 디자인 카드는 실제 한글 예문을 보여 줍니다. 디자인 변경은 기존 크기·위치를 보존합니다.
- **적용 대상**의 `이 자막만`은 개별 수정, 종류별 `공통`은 기본값을 사용하는 자막을 함께 수정합니다. 개별로 바꾼 항목만 공통 설정에서 분리됩니다.
- **같은 종류 모두 크기·위치 맞추기**는 현재 자막의 크기·위치를 공통값으로 정하고 같은 종류의 개별 크기·위치를 초기화합니다. 디자인과 문장·시간은 유지합니다. 한 번의 실행 취소로 복구합니다.
- 미리보기의 자막을 직접 끌어 이동하고 오른쪽 아래 손잡이로 크기를 조절합니다. 9방향 정렬 버튼, 자석 켜기/끄기, Alt 임시 해제, 방향키 1픽셀/Shift+방향키 10픽셀 이동을 지원합니다.
- 자막을 선택하고 타임라인의 양끝을 끌거나 시작·끝 초를 입력해 구간을 조절합니다. `S` 분할과 `Delete`는 선택된 자막에 적용합니다. 전체 제목은 구간 분할 없이 영상 전체에 표시됩니다.
- 한글 입력 중에는 편집 단축키가 작동하지 않습니다. 빈 문장은 출력되지 않으며, 긴 문장은 글자 크기를 자동 축소하지 않고 줄바꿈합니다.
- 글꼴·색상·외곽선·배경 세부 조절과 정렬 여백은 오른쪽 펼침 메뉴에 있습니다. 화면 밖으로 나간 자막은 표시하며 출력 전에 수정하도록 안내합니다.
- **내 자막 설정**은 디자인·크기·위치를 함께 PC에 저장합니다. 다른 프로젝트에서도 적용할 수 있습니다.
- 패널 경계와 타임라인 위 경계를 끌어 미리보기 공간을 조절합니다. **크게 보기**는 편집 패널을 접고, 버튼 또는 Esc로 돌아옵니다. 화면 배치 초기화 버튼은 기본 크기로 복원합니다.

## 저장·렌더링 계약

- 프로젝트 v4. v1~v3는 자막이 없는 상태로 마이그레이션합니다. 자막 2,000개까지 저장하며 이번 검증은 200개로 진행합니다.
- 일반/강조는 clipId와 정규화된 원본 30fps 반개구간으로 저장합니다. 트림은 보이는 교집합만 바꾸고, 분할은 양쪽 원본 구간에 해당하는 자막을 복제합니다. 이동·삭제·Undo/Redo도 클립 연결을 따릅니다.
- 제목은 clipId=null, inFrame=outFrame=0인 전체 구간 표식이며, 표시 범위는 현재 전체 타임라인 길이로 계산합니다. 한 프로젝트에 제목 하나를 둡니다.
- 글자 크기는 짧은 변 1080 기준, 위치는 기준점과 정규화 좌표로 저장합니다. 고정 위치의 기본값은 정렬 여백으로 계산하며 줄이 늘어나도 아래쪽 기준선이 유지됩니다.
- Noto Sans KR / Noto Serif KR 가변 글꼴을 OFL 원문과 함께 포함합니다. 사용자 시스템 글꼴에 의존하지 않습니다.
- 공통 Canvas 2D 렌더러가 투명 PNG와 크기를 생성합니다. 동일 PNG를 편집 화면과 출력에 사용합니다. 위치만 바꾸면 PNG를 재생성하지 않습니다.
- 출력은 자막 변경 시점별 합성 PNG를 ffconcat으로 연결한 단일 30fps 투명 오버레이입니다. 색 보정과 화면 맞춤 후 자막을 합성하며, 모든 시작/끝 구간은 프레임 경계로 검증합니다. 제목과 일반 자막 위에 강조 캡션을 표시합니다.
- 렌더링은 네트워크가 차단된 별도 숨김 Electron 창에서 수행합니다. 검증된 텍스트·스타일만 전달하며 임의 HTML·폰트 경로·스크립트를 입력받지 않습니다. 출력 완료/취소/실패 시 이번 출력용 PNG 작업 폴더를 정리합니다.
- `caption-presets.json`은 사용자 설정이고 `cache/captions/`는 재생성 가능한 작업 자료입니다. 화면 배치는 앱의 로컬 설정으로 관리합니다.

## 검증

- 단위 테스트: 레거시 마이그레이션, 자막 추가/중복 선택, 같은 종류의 구간 충돌, 클립 분할·트림·이동·삭제, 제목 전체 구간, 공통/개별 설정, 정렬 기준점.
- 실제 Electron 화면: 자막·제목·강조 동시 표시, 문장 수정, 디자인 선택, 공통 설정과 초기화, 자석/Alt/드래그 취소/단일 Undo, 크기 손잡이, 타임라인 길이·분할, 화면 확대, 패널 크기, 저장/복구.
- 6개 비율의 출력과 동일 PNG로 만든 독립 Canvas 합성을 비교합니다. 평균 RGB 차이 0.23~0.67/255, 자막 위치 탐색의 최적 이동량은 모든 비교에서 (0,0)픽셀이었습니다.
- 시작·끝 전후 12프레임에서 일반/강조/제목의 표시 유무를 실제 출력 픽셀로 검증했습니다. 클립 경계를 포함해 제목이 유지됩니다.
- 화면 밖 자막과 렌더링 실패는 해당 문장을 안내하고 출력을 중단합니다. 자막 이미지 생성 중·영상 인코딩 중 취소 시 완성 MP4와 임시 이미지가 남지 않는 것도 검증했습니다.
- 자막 200개를 실제 목록·타임라인에 표시하고 MP4로 내보냈습니다. 기존 미디어·색상·비율 검증 및 컷 편집/길이/이동/비율 화면 검증도 통과했습니다.
- 실제 촬영본 IMG_5651.MP4에 제목·흰 배경 자막·명조 강조를 함께 적용해 151프레임 MP4로 출력하고 화면을 확인했습니다. 작업 전후 원본 SHA256은 동일합니다. 예시 위치는 `artifacts/latest-caption-example.json`에 기록합니다.
- 자세한 결과는 `artifacts/latest-captions-desktop.json`, `latest-caption-render.json`, `latest-caption-gestures.json`과 연결된 report.json에 기록합니다.

이번 버전은 직접 입력한 정적 자막입니다. 자동 음성 인식, 자막 애니메이션, SRT 가져오기/내보내기, 임의 외부 폰트 추가는 포함하지 않습니다. 실제 검증은 Windows 11 한 대이며, 네이티브 파일 선택창은 자동 검증에서 대체했습니다.
