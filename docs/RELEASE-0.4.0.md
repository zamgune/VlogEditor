# 장면 · VlogTool v0.4.0

자막 꾸미기와 스타일 저장 기능을 확장하고, 앞부분 자르기·재생 동기화·내보내기를 개선했습니다.

- **빠른 내보내기:** 잘라낸 앞 구간을 건너뛰고, 색 보정 계산과 CPU 사용을 최적화했습니다. 같은 1080p 8초 시험 영상에서 색 보정 출력은 약 173초 → 3초, 기본 출력은 3.5초 → 2초로 줄었습니다. 실제 시간은 영상·효과·PC에 따라 달라집니다.
- **덮어쓰기:** 기존 파일명을 선택하면 Windows 확인 창에서 교체 여부를 선택합니다. 새 MP4가 완성·검증된 뒤 교체하며, 취소·실패 시 이전 파일을 보존합니다.
- **진행률:** 자막·꾸미기 준비, 영상 만들기, 확인·저장 단계를 구분하고 현재 단계 진행률·처리한 영상 길이·경과 시간을 표시합니다.
- **다양한 글자 서식:** 일부 단어에 다른 글꼴·크기·색을 적용하고, 나눔손글씨 펜 글꼴을 사용할 수 있습니다.
- **배경과 도형:** 자막·제목의 배경에 각도와 두 색을 조절하는 소프트/하드 그라데이션을 적용합니다. 독립된 사각형·타원을 놓고 색·라운드·테두리를 조절합니다.
- **스타일 묶음:** 여러 제목·자막·도형을 함께 저장·편집하고 기본 자막 스타일로 지정합니다.
- **복사와 정렬:** Ctrl+C/V로 자막을 복사합니다. 뒤쪽 빈 시간에 자동 배치하는 옵션과 다른 자막의 가장자리·가운데·간격에 맞추는 자석 기능을 제공합니다.
- **앞뒤 자르기:** 재생 위치에서 Q/W로 자르고, 드래그 중 잘라낼 구간을 확인합니다. 앞부분을 자른 영상의 소리와 재생선 시작 위치를 수정했습니다.

## 실행

`VlogTool-0.4.0-win-x64.zip`을 다운로드해 모두 압축 해제한 뒤 **Start-VlogTool.cmd**를 실행하세요. Node.js는 필요 없습니다. 첫 실행 시 영상 처리 도구를 다운로드하므로 인터넷 연결이 필요합니다. 이후 영상 처리는 PC에서 이루어집니다.

이전 프로젝트와 스타일 보관함은 열 때 변환됩니다. 새로 저장한 프로젝트는 v0.4.0 이상에서 열어 주세요. 원본 영상과 프로젝트 옆의 `.vlog.json.assets` 녹음 폴더를 함께 보관하세요.
