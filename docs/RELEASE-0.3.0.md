# 장면 · VlogTool v0.3.0

Windows에서 영상을 편집하고, 자막과 마이크 내레이션을 더할 수 있는 버전입니다.

## 주요 기능

- 영상의 앞쪽과 뒤쪽 자르기, 분할, 순서 이동과 실행 취소
- 마루 부리 5가지 굵기, Noto 글꼴과 자막 스타일·움직임
- 영상을 보며 마이크 녹음, 녹음 앞뒤 자르기·위치·음량 조절
- 화면 비율·색 보정, 프로젝트 저장과 MP4 내보내기

## 실행 방법

`VlogTool-0.3.0-win-x64.zip`을 다운로드하고 모두 압축 해제한 뒤 **Start-VlogTool.cmd**를 실행하세요. Node.js 설치는 필요 없습니다. 첫 실행에서 FFmpeg를 내려받으므로 인터넷 연결이 필요합니다. 이후 영상 처리는 PC에서 진행합니다.

Windows 11 x64에서 확인했으며 코드 서명은 아직 적용되지 않았습니다. 사용법은 [README](https://github.com/zamgune/VlogEditor#readme)를 참고하세요.

프로젝트를 옮길 때는 `.vlog.json`과 `.vlog.json.assets` 폴더를 함께 보관하세요. 원본 영상은 저장 당시 위치에서 읽습니다.

녹음 기능은 가상 마이크로 녹음·재생·MP4 출력·오류 복구를 검증했습니다. 실제 마이크별 입력 지연과 음질은 장치 환경에 따라 확인이 필요합니다.

39개 단위 검사와 빌드를 통과했으며, 배포용 실행 파일에서 가져오기·앞뒤 자르기·마루 부리 자막·녹음·저장·MP4 내보내기를 확인했습니다. `SHA256SUMS.txt`로 다운로드한 ZIP의 무결성을 확인할 수 있습니다.
