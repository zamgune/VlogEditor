# 0.7 · 여러 자막, 스타일 보관함과 움직임

## 사용하기

- **＋ 자막 / ＋ 강조**를 누를 때마다 새 자막을 만듭니다. 같은 시간에 같은 종류의 자막을 여러 개 표시할 수 있습니다. 일반 자막은 클립 전체, 강조는 현재 위치부터 최대 2초입니다. **＋ 전체 제목**은 기존처럼 프로젝트당 하나이며 영상 전체에 표시됩니다.
- 왼쪽 목록에서 문장을 편집하고 Enter로 줄바꿈합니다. 미리보기에서 위치·크기를 조절하고, 오른쪽 **복제 / 삭제 / 앞으로 / 뒤로**로 자막을 관리합니다. 가려진 자막도 목록에서 선택할 수 있습니다. 새 자막은 실제 글자 이미지 크기를 확인해 화면 안에 배치하고, 앞뒤 순서는 현재 장면에 보이는 자막을 기준으로 바꿉니다.
- 겹치는 자막은 타임라인의 여러 줄로 나눠 표시합니다. 화면 앞뒤 순서와 타임라인 줄은 별개입니다. 세로 스크롤바 또는 **Shift+휠**로 자막 줄을 탐색합니다. 기존 휠 좌우 이동과 Ctrl+휠 확대/축소도 유지합니다.
- 오른쪽 **스타일 / 꾸미기 / 움직임** 탭에서 편집합니다. 적용 대상은 기본적으로 **이 자막만**이며 종류별 공통 설정도 사용할 수 있습니다.

### 스타일과 즐겨찾기

- 기본·대사, 감성·메모, 장소·정보, 강조·리액션, 제목·인트로의 5개 분류에 각각 4개, 총 **20개** 스타일을 제공합니다. 기존 8개의 ID와 디자인은 유지합니다.
- **전체 / ★ 즐겨찾기 / 내 스타일**, 이름 검색, 분위기별 필터를 사용합니다. 기본 카드와 저장 카드 모두 ☆로 즐겨찾기에 추가합니다.
- **현재 스타일 저장**은 디자인과 등장·퇴장 효과, 선택 적용용 크기·위치를 PC에 저장합니다. 최대 100개이며 다른 프로젝트에서도 재사용합니다.
- 스타일 적용은 기본적으로 디자인과 움직임만 바꾸고 글자 크기·위치·최대 폭을 유지합니다. **크기·위치도 적용**을 체크하면 모두 적용합니다.
- 내 스타일 카드를 선택하면 이름 변경, 현재 설정으로 덮어쓰기, 복제, 삭제를 사용할 수 있습니다. 기존 자막은 저장 스타일의 복사본을 가지므로 보관함 수정·삭제의 영향을 받지 않습니다.

### 꾸미기

고딕·명조, 굵기, 크기, 글씨 색상, 이중 외곽선의 색과 두께, 배경 색과 0–100% 불투명도, 둥글기·안쪽 여백, 그림자 강도를 조절합니다. 외곽선·배경·그림자는 각각 끌 수 있습니다. 숫자와 슬라이더를 함께 제공합니다.

문단 좌/중/우 정렬, 줄 간격 1.2–2.4배, 최대 폭 20–100%, 화면 9방향 정렬과 기준 여백을 제공합니다. 문단 정렬과 화면 위치 정렬은 독립적입니다.

### 움직임

- 등장과 퇴장을 각각 **없음 / 페이드 / 팝 / 슬라이드**로 설정합니다. 슬라이드는 위·아래·왼쪽·오른쪽을 선택합니다.
- 기본 효과 시간은 0.3초이며 0.1–1초, 30fps 프레임 단위로 조절합니다. 짧은 구간에서는 효과를 비례 축소해 최소 한 프레임을 온전히 표시합니다.
- **움직임 미리보기**는 선택한 자막 시작부터 재생합니다. 일시정지·탐색·출력 모두 해당 프레임의 움직임을 사용합니다. 편집용 선택 테두리는 기준 위치를 보여 줍니다.
- 트림과 분할 뒤 효과는 실제 보이는 각 구간을 기준으로 다시 계산합니다. 화면 안의 기준 자막 위치는 검사하고, 효과로 잠깐 화면 경계를 지나는 부분은 캔버스에서 잘라 표시합니다.

## 저장과 렌더링

- 프로젝트 **v5**, 기존 v1–v4 읽기 지원. 이전 파일에 움직임 없음, 가운데 문단 정렬, 1.4배 줄 간격을 채웁니다. 기존 일반 자막 → 전체 제목 → 강조의 합성 순서를 명시적인 `zOrder`로 이전합니다.
- 자막은 클립과 원본 30fps 반개구간에 연결합니다. 겹침은 허용하되 원본 참조·유효한 구간 검사는 유지합니다. 클립 트림·분할·이동·삭제, 자동 저장, Undo/Redo도 연결된 자막에 적용됩니다.
- `caption-presets.json`은 `{version:1, styles, favorites}` 형식입니다. 이전 배열 형식도 읽습니다. 즐겨찾기 키는 기본 스타일과 사용자 스타일을 구분합니다. 쓰기는 직렬화하고 임시 파일을 교체합니다. 읽기 실패 시 빈 보관함으로 덮어쓰지 않습니다.
- 같은 글자 PNG와 공통 프레임별 alpha/scale/translation 함수를 DOM 미리보기와 Canvas 출력에 사용합니다. 위치나 움직임만 바뀌면 글자 이미지를 다시 생성하지 않습니다.
- 정적인 구간은 한 장을 재사용하고 움직이는 구간만 프레임별 PNG를 생성해 기존 ffconcat 오버레이로 출력합니다. 글자 캐시는 64개, 합성 장면 조회 캐시는 256개로 제한하고 순차 처리합니다. 출력 완료·실패·취소 시 작업별 임시 자료를 정리합니다.

## 검증

- `npm test`: 36개 통과. v1–v4 이전, 겹침·분할·트림, 순서·복제, 보관함 이전/검사, 외관만 적용, 효과 길이와 경계, 정적 구간 재사용을 포함합니다.
- `test:captions`, `test:caption-gestures`: 실제 Electron에서 기존 자막 편집, 크기·드래그·자석·취소·Undo/Redo, 6개 비율 배치, 한글 입력, 재시작 복구를 검증합니다.
- `verify:captions`: 기존 6개 비율 정적 출력과 위치가 이전 결과와 일치합니다. 화면 밖/긴 자막 실패, 이미지 생성 중·인코딩 중 취소와 임시 파일 정리를 확인합니다.
- `test:caption-upgrade`: 일반 자막 3개 동시 표시, 여러 타임라인 줄, 복제·삭제·순서·Undo, 겹친 구간 조절, 즐겨찾기·보관함 전체 작업, 프로젝트 전환·재시작 유지, 불투명도·문단 정렬·줄 간격·재생을 검증합니다.
- 애니메이션은 6개 비율에서 각각 9프레임을 독립 Canvas 합성과 비교합니다. 한 프레임짜리 자막도 포함합니다. 200개 자막·10개 동시 움직임의 4초 영상으로 편집/출력 시간과 프로세스 메모리를 기록합니다. 이는 짧은 합성 영상 기준이며 장시간 실촬영 브이로그의 성능 보장은 아닙니다.
- 최신 결과는 `artifacts/latest-caption-upgrade.json`, 정적 출력은 `latest-caption-render.json`, 조작 검증은 `latest-caption-gestures.json`에 있습니다. 연결된 폴더에 화면 캡처, 20종 스타일 미리보기, MP4와 상세 보고서를 보존합니다.

이번 범위에 자동 음성 자막, 글자별 색상, 타자기·반복 효과, 외부 폰트 추가는 포함하지 않습니다.
