# 여러 제목과 글 그룹

`＋ 전체 제목`을 반복해서 눌러 제목을 여러 개 만듭니다. 각 제목은 별도의 문구·크기·배경·위치·움직임을 가지며, 복제·삭제·실행 취소도 가능합니다. 새 제목은 기존 제목에서 조금 떨어진 위치에 생기고, 미리보기에서 직접 옮길 수 있습니다.

## 예: 두 줄 인트로 저장

1. 제목을 두 개 추가합니다.
2. 첫 제목은 `일단 이렇게 시작해보겠습니다.`, 글자 크기는 `60`으로 설정합니다.
3. 둘째 제목은 `에피소드 2`, 글자 크기는 `30`으로 설정하고 배경을 켭니다.
4. 자막 목록에서 두 글의 **그룹에 포함**을 체크하고, 그룹 이름을 입력한 뒤 **선택한 글을 새 그룹으로 저장**을 누릅니다.
5. **저장한 그룹**을 펼치고 그룹을 선택해 **그룹 불러오기**를 누릅니다. 각 글을 수정한 뒤 **선택한 글로 그룹 덮어쓰기**를 누르면 기존 그룹을 갱신합니다. 새 이름으로 별도 저장할 수도 있습니다.

일반 자막·강조 캡션·제목을 섞어 저장할 수 있습니다. 문구, 글꼴, 크기, 배경, 위치, 움직임과 겹치는 순서를 함께 보관합니다. 제목은 영상 전체에 표시되고 일반·강조 자막은 선택한 클립 안에 배치됩니다. 원래 표시 구간보다 짧은 클립에 넣으면 그 길이에 맞춥니다. 그룹은 이 PC의 보관함에 저장되어 다른 프로젝트와 앱 재실행 후에도 사용할 수 있습니다. 그룹은 최대 50개, 그룹 안의 글은 최대 50개입니다.

불러온 글은 각각 독립적으로 편집됩니다. 보관함의 그룹을 변경하거나 삭제해도 이미 영상에 넣은 글은 유지됩니다. 그룹 불러오기는 실행 취소 한 번으로 되돌릴 수 있습니다.

## 한 장면 안에서 자막 시간 나누기

**＋ 자막** 또는 **＋ 강조**로 추가한 글은 현재 재생 위치에서 시작합니다. 자막을 선택하면 오른쪽 위 **표시 시간**에서 시작·끝·길이를 초 단위로 입력할 수 있습니다. 시간은 선택한 장면의 시작을 0초로 계산하며, **Enter**로 반영합니다.

3초 장면에서 다음과 같이 설정할 수 있습니다.

| 자막 | 시작 | 끝 |
| --- | --- | --- |
| 1번, 2번 | 0초 | 1.5초 |
| 3번, 4번 | 1.5초 | 3초 |

자막 하나씩 순서대로 보여 주려면 각 구간에 하나만 넣으세요. 여러 자막의 시간이 같으면 동시에 표시되며, 화면 안의 위치는 미리보기에서 각각 끌어 조절합니다.

타임라인 자막 막대의 **가운데**를 끌면 길이를 유지하며 시간을 옮기고, **양끝**을 끌면 시작이나 끝을 바꿉니다. 장면 전체를 차지하는 자막은 먼저 길이를 줄여야 옮길 공간이 생깁니다. **현재 위치로 이동**은 길이를 유지해 재생 위치로 옮기며 장면 끝을 넘으면 끝에 맞춥니다. **장면 전체**로 표시 구간을 되돌릴 수 있습니다. 드래그는 Esc로 취소하고 실행 취소 한 번으로 되돌립니다.

그룹에는 자막별 표시 시간도 함께 저장됩니다. **전체 제목**은 영상 전체에 표시되므로, 짧은 제목을 넣으려면 일반 자막에 제목 디자인을 적용하세요.

## 숫자 입력

크기, 불투명도, 외곽선, 여백, 줄 간격, 움직임 시간과 자막 표시 구간은 숫자를 모두 입력한 뒤 **Enter** 또는 다른 곳을 클릭하면 반영됩니다. 입력 중에는 최소값·최대값으로 강제 변경하지 않습니다. 빈칸은 이전 값으로 돌아가고 **Esc**로 입력을 취소할 수 있습니다. 슬라이더는 바로 반영됩니다.

## 저장 형식과 확인

프로젝트는 형식 7, 글 보관함은 형식 2로 저장합니다. 이전 프로젝트(1~6)와 이전 스타일 보관함을 열면 변환하며, 기존 문구·스타일·즐겨찾기는 유지합니다. 형식 7 프로젝트는 공개된 0.3.0 앱 대신 이 기능이 반영된 앱에서 여세요.

`npm run test:caption-groups`는 두 제목, 숫자 한 자리씩 입력, 소수·빈칸·Esc, 실행 취소·다시 실행, 그룹 저장·불러오기·덮어쓰기·이름 변경·삭제, 단일 스타일과 함께 보관, 재시작, MP4의 두 제목 출력과 작은 창을 검사합니다. 가상 미디어와 별도 테스트 보관함을 사용합니다.
