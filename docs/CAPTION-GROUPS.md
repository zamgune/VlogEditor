# 여러 제목·꾸미기 묶음과 기본 자막

`＋ 전체 제목`을 반복해서 눌러 제목을 여러 개 만듭니다. 각 제목은 별도의 문구·크기·배경·위치·움직임을 가지며, 복제·삭제·실행 취소도 가능합니다. 새 제목은 기존 제목에서 조금 떨어진 위치에 생기고, 미리보기에서 직접 옮길 수 있습니다.

## 자막을 나란히 놓거나 위아래로 정렬

미리보기 위 **자석 켜짐** 상태에서 자막을 다른 자막 근처로 끌어 보세요. 일반 자막·강조 캡션·전체 제목 모두 같은 방식으로 정렬됩니다.

- 다른 자막의 **왼쪽·가운데·오른쪽**, **위·가운데·아래**에 맞춰 붙습니다. 화면 기준 정렬도 가로·세로 각각 작동합니다.
- 자막 아래·위·옆에 놓으면 기본 간격으로 붙습니다. 짧은 변이 1080인 영상에서는 **24px**이며 화면 크기에 비례합니다.
- 이미 두 자막이 배치되어 있으면 세 번째 자막을 끌어 **같은 간격**으로 이어 놓거나 두 자막 사이에 배치할 수 있습니다.
- 맞춰지는 기준 자막에는 점선 테두리, 정렬 위치에는 안내선, 사이 간격에는 숫자가 표시됩니다. 현재 재생 위치에 표시되는 자막만 기준이 됩니다.
- **Alt를 누른 채 끌면** 자석을 잠시 끄고 자유롭게 움직입니다. 위의 자석 버튼으로 완전히 끌 수도 있습니다. **Esc**는 이동 취소, **Ctrl+Z**는 이동 한 번 되돌리기입니다.

## 예: 두 줄 인트로 저장

1. 제목을 두 개 추가합니다.
2. 첫 제목은 `일단 이렇게 시작해보겠습니다.`, 글자 크기는 `60`으로 설정합니다.
3. 둘째 제목은 `에피소드 2`, 글자 크기는 `30`으로 설정하고 배경을 켭니다.
4. 자막 목록에서 두 글의 **그룹에 포함**을 체크하고, 묶음 이름을 입력한 뒤 **선택한 글·꾸미기 저장**을 누릅니다. 도형도 저장하려면 **함께 저장할 꾸미기**에서 체크하세요.
5. **저장한 묶음**을 펼치고 묶음을 선택해 **그룹 불러오기**를 누릅니다. 각 글과 도형을 수정한 뒤 **선택한 글·꾸미기로 덮어쓰기**를 누르면 기존 묶음을 갱신합니다. 새 이름으로 별도 저장할 수도 있습니다.

일반 자막·강조 캡션·제목과 도형을 섞어 저장할 수 있습니다. 문구, 부분 글꼴·크기, 배경 그라데이션, 위치, 움직임, 도형의 색·둥글기·테두리와 겹치는 순서를 함께 보관합니다. **그룹 불러오기**에서는 제목이 영상 전체에 표시되고 일반·강조 자막과 장면 도형은 선택한 클립 안에 배치됩니다. 원래 표시 구간보다 짧은 클립에 넣으면 그 길이에 맞춥니다. 묶음은 이 PC의 보관함에 저장되어 다른 프로젝트와 앱 재실행 후에도 사용할 수 있습니다. 묶음은 최대 50개, 묶음 안의 글·도형은 각각 최대 50개입니다.

불러온 글과 도형은 각각 독립적으로 편집됩니다. 보관함의 묶음을 변경하거나 삭제해도 이미 영상에 넣은 글과 도형은 유지됩니다. 묶음 불러오기는 실행 취소 한 번으로 함께 되돌릴 수 있습니다.

## 꾸며 둔 화면을 기본 자막으로 저장

1. 저장할 제목·도형이 보이는 재생 위치로 이동합니다.
2. 왼쪽 **자막 목록 → 현재 화면 선택**을 누릅니다. 오른쪽 **스타일 → 제목·꾸미기 함께 저장하기**로도 선택할 수 있습니다.
3. 필요 없는 글은 목록의 **그룹에 포함**, 도형은 **함께 저장할 꾸미기**에서 체크를 해제합니다.
4. 이름을 입력하고 **기본 자막 스타일로 저장**을 누릅니다.
5. 원하는 장면과 재생 위치에서 **＋ 자막**을 누르면 저장한 모든 글·도형이 함께 추가됩니다. 문구는 저장한 내용으로 시작하며 각각 바꿀 수 있습니다.

기본 자막으로 추가할 때는 저장 당시 제목·강조 여부와 관계없이 모든 글이 일반 자막이 됩니다. 글과 도형 모두 현재 재생 위치부터 장면 끝까지 표시됩니다. 이후 글의 시간은 자막 속성에서, 도형의 시간은 도형 속성에서 각각 편집합니다. **＋ 강조**와 **＋ 전체 제목**은 기존 방식으로 추가합니다.

이미 저장한 묶음은 **저장한 묶음 → 기본 자막으로 지정**으로 바꿀 수 있습니다. **기본 지정 해제**를 누르면 기본 제공 자막으로 돌아가고 저장한 묶음은 남습니다. 기본 묶음을 덮어쓰면 다음에 추가하는 자막부터 바뀐 구성을 사용합니다. 기본 묶음을 삭제하면 기본 지정도 해제됩니다.

## 한 장면 안에서 자막 시간 나누기

**＋ 자막** 또는 **＋ 강조**로 추가한 글은 현재 재생 위치에서 시작합니다. 자막을 선택하면 오른쪽 위 **표시 시간**에서 시작·끝·길이를 초 단위로 입력할 수 있습니다. 시간은 선택한 장면의 시작을 0초로 계산하며, **Enter**로 반영합니다.

3초 장면에서 다음과 같이 설정할 수 있습니다.

| 자막 | 시작 | 끝 |
| --- | --- | --- |
| 1번, 2번 | 0초 | 1.5초 |
| 3번, 4번 | 1.5초 | 3초 |

자막 하나씩 순서대로 보여 주려면 각 구간에 하나만 넣으세요. 여러 자막의 시간이 같으면 동시에 표시되며, 화면 안의 위치는 미리보기에서 각각 끌어 조절합니다.

타임라인 자막 막대의 **가운데**를 끌면 길이를 유지하며 시간을 옮기고, **양끝**을 끌면 시작이나 끝을 바꿉니다. 장면 전체를 차지하는 자막은 먼저 길이를 줄여야 옮길 공간이 생깁니다. **현재 위치로 이동**은 길이를 유지해 재생 위치로 옮기며 장면 끝을 넘으면 끝에 맞춥니다. **장면 전체**로 표시 구간을 되돌릴 수 있습니다. 드래그는 Esc로 취소하고 실행 취소 한 번으로 되돌립니다.

그룹에는 자막별 표시 시간도 함께 저장됩니다. **전체 제목**은 영상 전체에 표시되므로, 짧은 제목을 넣으려면 일반 자막에 제목 디자인을 적용하세요.

## 자막 복사·붙여넣기와 자동 배치

자막 목록, 미리보기 또는 타임라인에서 자막을 선택한 뒤 **Ctrl+C**로 복사하고 **Ctrl+V**로 붙여넣습니다. 문구·부분 글꼴·크기·그라데이션·위치·움직임을 함께 복사하며, 원문을 나중에 바꿔도 복사해 둔 내용은 유지됩니다. 문구·숫자 입력칸에 커서가 있을 때는 글자 복사·붙여넣기로 동작합니다.

왼쪽 **자막 목록 → 자막 복사·붙여넣기 · Ctrl+C / V**를 펼치면 복사·붙여넣기 버튼과 **뒤쪽 빈 시간에 자동 배치** 옵션이 있습니다. 처음에는 꺼져 있으며, 설정은 다른 프로젝트와 앱 재실행 후에도 유지됩니다.

- **옵션 켜짐:** 같은 장면에서 복사한 자막의 끝 이후, 일반·강조 자막과 겹치지 않고 복제본 길이가 들어가는 첫 빈 구간에 배치합니다. 표시 길이와 화면 위치를 유지합니다. Ctrl+V를 반복하면 뒤쪽 빈 구간을 계속 찾습니다.
- **옵션 꺼짐 또는 빈 공간 부족:** 기존 시간에 복제합니다. 겹친 글을 구분하기 쉽도록 화면 위치는 조금 옮깁니다. 전체 제목도 기존처럼 영상 전체에 표시됩니다.
- **다른 장면·프로젝트에 붙여넣기:** 선택한 장면의 재생 위치에 넣고 장면 끝을 넘는 부분만 줄입니다. 원래 표시되던 길이와 디자인을 복사합니다.

옵션은 오른쪽 **복제** 버튼에도 적용됩니다. 복사 내용은 앱 안에서 보관되며 앱을 종료하면 비워집니다. 도형은 별도 항목입니다. 글과 도형을 함께 재사용하려면 위의 묶음 저장을 이용하세요. 붙여넣기와 복제는 **Ctrl+Z** 한 번으로 되돌릴 수 있습니다.

## 숫자 입력

기본 크기, 불투명도, 외곽선, 여백, 줄 간격, 움직임 시간과 자막 표시 구간은 숫자를 모두 입력한 뒤 **Enter** 또는 다른 곳을 클릭하면 반영됩니다. **문구 → 선택 크기**는 입력하는 즉시 반영됩니다. 입력 중에는 최소값·최대값으로 강제 변경하지 않습니다. 빈칸은 이전 값으로 돌아가고 **Esc**로 입력을 취소할 수 있습니다. 슬라이더는 바로 반영됩니다.

## 저장 형식과 확인

최신 소스는 프로젝트 형식 8, 글 보관함 형식 4로 저장합니다. 이전 프로젝트(1~7)와 이전 스타일 보관함을 열면 변환하며, 기존 문구·스타일·즐겨찾기는 유지합니다. 부분 글꼴과 배경 그라데이션, 도형도 묶음에 함께 저장됩니다. 새 형식 프로젝트는 공개된 0.3.0 앱 대신 이 기능이 반영된 앱에서 여세요. [부분 글꼴과 도형 사용법](RICH-TEXT-DECORATIONS.md)

`npm run test:caption-groups`는 두 제목, 숫자 한 자리씩 입력, 소수·빈칸·Esc, 실행 취소·다시 실행, 그룹 저장·불러오기·덮어쓰기·이름 변경·삭제, 단일 스타일과 함께 보관, 재시작, MP4의 두 제목 출력과 작은 창을 검사합니다. 가상 미디어와 별도 테스트 보관함을 사용합니다.

`npm run test:caption-bundles`는 제목 두 개·부분 서식·그라데이션·도형 두 개를 기본으로 저장하고, 다른 프로젝트의 새 자막에 적용·수정·덮어쓰기·이름 변경·해제·삭제·재실행하는 과정을 검사합니다. 표시 전/시작/끝 MP4를 원래 디자인과 비교하고 1100×760 창도 확인합니다.

`npm run test:caption-copy`는 실제 Ctrl+C/V, 문구 입력과 단축키 구분, 빈 시간 자동 배치·반복 붙여넣기·공간 부족·전체 제목·Undo/Redo, 복제 버튼, 다른 프로젝트, 한국어 키보드 배열, 옵션 재시작 보존과 작은 창을 검사합니다.
